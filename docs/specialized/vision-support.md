# 提供盲人指引前，先询问对方需要什么

每个人需要的帮助不同。先介绍自己、询问需求，再确认对方希望怎样获得帮助。以下内容根据 RNIB 的指引资料整理。[参考来源：RNIB](https://www.rnib.org.uk/living-with-sight-loss/supporting-others/guiding-a-blind-or-partially-sighted-person/)

<ServiceFlow kind="vision" />

## 先征询，再提供帮助

直接与对方交流，询问是否需要帮助。如果需要指引，请对方说明自己习惯或偏好的引导方式。不要仅根据外表推测对方需要什么。

可以这样开始：“你好，我是这里的志愿者。需要我帮你确认路线吗？”如果对方需要陪同，再询问：“你希望我怎样带你过去？”

## 盲人指引中的环境说明

- 接近台阶或路缘时，说明位置，以及向上还是向下。
- 提示前方障碍，并说清所在位置。
- 离开时告知对方，避免让对方无法判断你是否还在身边。

### 把环境提示讲具体

下面是根据已确认的现场信息调整的示例：

- “前面有一级向上的台阶，我们先停一下。”
- “右前方有一张桌子，我先确认从哪侧经过更方便。”
- “我们已经到咨询台。我会告诉你咨询人员在哪里，再离开。”

提示路线时说明方向和参照物，把环境变化提前说清。涉及实际陪同行走、台阶和就座时，结合专业示范学习，并尊重对方习惯的方式。
