# 急救科普：认识现场协作与学习路径

遇到突发不适或受伤，及时呼救、说明准确的位置，并按急救调度员的指导配合。具体急救动作通过专业示范和有指导的实践学习。

## 服务前，先熟悉现场信息

到达服务点后，可以向负责人确认现场地址、可供急救人员进入的入口、急救用品和 AED 的位置，以及当班联络方式。把这些信息和项目安排放在一起，遇到情况时更容易找到。

## 拨打 120 时，说清什么

**在中国大陆，医疗急救电话为 120。** 通话时按调度员的问题回答，重点说明准确地点、发生的情况和可回拨的电话。深圳市卫生健康委员会的案例提醒，地点说明应包括所在区域、道路、建筑或附近明显参照物。[参考：深圳市卫生健康委员会](https://wjw.sz.gov.cn/wzx/content/post_11239507.html)

在校园内，可以提前准备这样的地址说明框架：

> 深圳市……区，深圳大学……校区，……楼……入口。这里有人突发不适，现场情况是……。可以回拨的电话是……。

省略号处填写现场已确认的信息；按调度员要求继续补充，并保持电话可联系。现场救助按调度员指导开展。[参考：深圳市人民政府关于紧急呼救的提醒](https://www.sz.gov.cn/cn/xxgk/zfxxgj/zwdt/content/post_12409333.html)

## 志愿者可以怎样配合现场

如果现场有多位人员，由负责人协调联络、入口接应和通道引导，避免重复传话。说明已经确认的情况，给专业救援人员留出工作空间。活动负责人需要同步联系，但不要因等待内部回复而延误紧急呼救。

## 专业学习可以从哪些主题开始

| 主题 | 学习时关注什么 |
| --- | --- |
| 现场评估与呼救 | 怎样描述情况、地点和联系方式，如何配合调度员 |
| 心肺复苏（CPR） | 跟随专业示范，结合有指导的练习学习操作 |
| 自动体外除颤器（AED） | 认识设备、提示信息和使用情境，结合课程练习 |
| 创伤救护与常见急症 | 学习现场处理原则，理解哪些情况需要专业支持 |

这些主题参考了[中国红十字会救护员培训内容](https://www.redcross.org.cn/html/2019-01/55969.html)和[深圳市急救中心的公众急救培训介绍](https://wjw.sz.gov.cn/szsjjzx/zxxx/content/post_12056753.html)。课程安排以机构最新公告为准。
