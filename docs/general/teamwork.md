# 知道自己如何配合

了解自己的任务，也了解工作怎样与其他同学衔接。团队协作需要清楚的分工、可找到的联络人，以及完整的交接信息。

## 先确认分工

- 确认自己负责的任务、工作区域和服务时段。
- 找到与自己直接配合的搭档或负责人。
- 了解进度反馈、临时调整和问题上报的渠道。

发现任务重复、遗漏或与现场需要不符时，及时反馈，由负责人协调安排。

## 交接时讲清楚

交接可以围绕四项信息展开：

1. **已完成的事项。** 哪些工作已经结束，哪些仍在进行？
2. **待处理的问题。** 有什么需要下一位同学继续跟进？
3. **资料与物品。** 相关文件、物品或工作记录放在哪里？
4. **联络方式。** 发生问题时需要联系谁？

重要信息请接班同学确认，避免只依靠猜测完成工作。

## 发生变化时及时同步

时间、区域或任务发生调整后，先核实新的安排，再同步给相关同学。临时离开岗位或无法继续参加时，提前向负责人说明，完成必要交接。

## 服务结束后一起复盘

简要记录实际安排与原计划有哪些差异，哪些协作方式有效，下一次可以怎样改进。描述事实和方法，比只评价某个人表现如何更方便大家继续学习。

## 一份交接说明怎么写

下面是可替换内容的写法，地点和人员均需按实际项目填写：

> 入口咨询已完成本时段工作。还有两位来访者需要确认会场位置，已请他们在咨询台等候。路线图在资料夹第一页，剩余胸牌在桌下收纳箱。下一班请先确认是否收到场地调整通知；不清楚时联系当班负责人。

交接后，让接班同学复述需要继续处理的事项，再确认物品位置。服务记录只保留工作需要的信息；公开复盘时，可将姓名和联系方式改成岗位名称。

## 复盘可以记三件事

1. 实际发生了什么，和原计划有什么差异？
2. 哪种沟通或配合方式解决了问题？
3. 下次需要提前准备哪份信息或物品？
