# 清楚表达，认真倾听

先了解对方需要什么，再说明自己能够提供的帮助。清楚的沟通可以从简短、具体的表达开始。

## 先听清需求

给对方把问题说完整的时间。如果没有听清，可以用自己的话复述，再请对方确认。

例如：“你是想了解前往服务点的路线，还是想确认活动开始的时间？”

## 把说明讲具体

说明地点、时间和下一步安排时，尽量使用明确的信息。与其说“去那边问”，可以说明：“请到入口旁的咨询台，那里有负责签到的同学。”

对于自己不了解的信息，先核实再答复。需要转交问题时，告诉对方应联系谁，以及可以怎样联系。

## 尊重不同的沟通方式

如果对方没有理解，可以换一种表达方式，或根据需要使用文字、清楚的地点名称等信息。不要把没有及时回应直接理解为不愿配合。

面向听障或视障人士的服务，可继续阅读 [手语与听障沟通](/specialized/sign-language) 和 [盲人指引与视障服务](/specialized/vision-support)。

## 有分歧时，先确认事实

遇到临时调整、误解或投诉时，先听清问题，说明已确认的信息，再联系负责人员协调。不要对尚未核实的安排作出保证。

完成沟通后，可以简单确认：“这样说明清楚吗？还有什么需要我帮你确认的吗？”

## 把一句话说得更清楚

| 场景 | 可以这样表达 |
| --- | --- |
| 对方没有听清 | “我换一种说法：集合地点是图书馆正门。” |
| 需要查证信息 | “这个安排我还需要确认，请稍等，我联系负责人。” |
| 需要请别人协助 | “这件事由咨询台负责。我可以告诉你位置，或帮你联系当班同学。” |
| 无法按原计划提供帮助 | “原定入口暂时关闭，目前可以走东侧入口。我先确认这条路线是否适合你。” |

这些表达是可按现场情况调整的示例。涉及具体路线、时间和承诺时，先确认信息，再替换进自己的说明。

## 用文字补充口头说明

路线、时间和联系人较多时，可以把信息写成短句。一次说明一件事，先写“要做什么”，再写“在哪里、什么时候”。发送前核对地点名称、日期和联络方式。

例如：

> 14:00 在图书馆正门集合。到场后，请到入口旁的咨询台签到。如需调整集合地点，请联系项目负责人。
