# 活动报账填写与材料整理指南

活动结束后，先整理票据，再填写报账表。表格按需下载，具体提交要求与财务负责人确认。

## 1. 准备材料

- 发票、付款记录及必要的购物明细。
- 活动名称、时间、参与人数与现场照片。

## 2. 填写报账表

在 <DownloadLink href="/downloads/reimbursement/expenses.xlsx" filename="经费报账表（活动结束后）.xlsx" plain>经费报账表</DownloadLink> 中填写活动信息，每笔支出列清物品、单价、数量、金额和付款方式。按实际支出填写，核对合计与票据金额。

示例：横幅｜80 元｜条｜2｜160 元｜实际付款方式。

用 <DownloadLink href="/downloads/reimbursement/activity-proof.docx" filename="活动证明（活动后）.docx" plain>活动证明</DownloadLink> 补充活动信息与照片。
