# PX 内容评价规则

文章末尾保留“这篇内容对你有帮助吗？”以及两个按钮：

- 拇指图标：有用，旁边显示数量。
- 差评表情：没帮助，旁边显示数量。

每篇文章分别记录。同一浏览器只有一个有效选择，点击另一项可以切换，再次点击已选项可以取消。无需填写文字或个人信息。

当前版本接入 Cloudflare Workers + D1，共享计数保存在云端；本地仅保存随机匿名浏览器标识。刷新页面、重新进入文章或切回标签页时获取最新计数；提交成功后通知同一浏览器的其他标签页刷新。不同浏览器、清除本地存储后可再次评价，不作为身份验证或正式考核。

旧版本地选择不自动计入云端。数字未获取时显示“—”；请求失败会提示服务暂时不可用，操作频繁则提示稍后再试。只有接口确认成功后才更新选择和数量。接口当前使用 `workers.dev` 地址，部分网络存在 DNS 解析或访问限制；更换域名时需同时更新前端接口地址及 Worker 的来源允许名单。维护细节见 `feedback-worker/README.md`。
